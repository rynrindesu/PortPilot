reschedule_operations tool
---------------------------
What it does:
Takes a ranked scheduling option selected by the agent, revalidates it against
the latest schedule, and safely applies the resource changes to the database.

Flow:
Ranked option selected
-> Convert datetime strings (Tool calls use JSON strings, but scheduling calculations need Python datetime objects)
-> Revalidate option (Check that the option is still valid against the latest schedule)
-> Lock affected resources (Prevent another scheduling update from changing the same resources at the same time)
-> Re-check conflicts
-> Update resource allocations
-> Record changes in audit log

Logic:
- If revalidation fails, nothing is changed.
- If revalidation modifies the option, the updated version is applied.
- All changes are atomic: either all succeed or all are rolled back.
- The agent provides a reason explaining the scheduling priorities/trade-offs
  behind its selection.
- Revalidation checks validity; it does not re-rank the options.

* Important: Tool parameters may change later depending on how graph state stores and
  passes ranked options.



flag_for_review tool
--------------------

What it does:
Flags a vessel's affected resource allocation for human review when
get_ranked_options() returns no valid scheduling options for the vessel.

Flow:
No valid scheduling options
-> Find the vessel's current resource allocation
-> Mark allocation as pending_review
-> Record the reason in schedule_changes
-> Return outcome = human_review

Logic:
- resource allocation's status is changed to pending_review in db.
- schedule_changes table's execution_mode is recorded as human_review in db.
- decision_score is None because no ranked option was applied.
- The tool handles one resource_type per call.
